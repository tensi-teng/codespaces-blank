# ARGUS Security & Privacy Standard

## Development
Only synthetic or properly anonymized data should enter source control. Secrets belong in environment variables or a managed secret store; `.env` is excluded from Git.

## Production Controls
Use least-privilege database accounts, TLS, encryption at rest, role-based access, audit logs, backups, retention/deletion rules and controlled exports.

## Responsible Use
Academic indicators should not be treated as evidence of mental-health conditions, character, misconduct or guaranteed future outcomes. Human review is required for consequential action.
